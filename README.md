# Квест невесты 🍋

Интерактивный квест для девичника: три раунда, баллы и финальный вердикт «готовность к свадьбе».

- **Раунд 1 — Угадай жениха**: невеста угадывает ответы жениха (вписываются заранее в настройке).
- **Раунд 2 — Наша история**: вопросы на память о деталях отношений.
- **Раунд 3 — Испытания**: колода карт с фантами.
- **Финал**: процент готовности, разбивка по раундам, звание и шуточный прогноз.

## Как открыть квест

Игра — один файл `index.html`, интернет и установка программ не нужны.

**Способ 1 — скачать архив (самый простой):**

1. На странице репозитория нажмите зелёную кнопку **Code** → **Download ZIP**.
2. Распакуйте архив в любую папку.
3. Дважды кликните по файлу `index.html` — квест откроется в браузере.

**Способ 2 — через git:**

```
git clone https://github.com/iriskazaraeva/bride-quest.git
```

и откройте `bride-quest/index.html` в браузере.

Рассчитано на горизонтальный экран ноутбука; подойдёт любой современный браузер (Chrome, Edge, Safari, Firefox).

## Подготовка перед девичником (для организатора)

1. Откройте квест и нажмите ссылку **«Настройка для организатора»** внизу обложки — невеста не должна подглядывать!
2. Впишите имена невесты и жениха.
3. Заранее узнайте у жениха ответы на 8 вопросов раунда 1 и впишите их в поля. Пустые поля тоже работают — тогда совпадение ответа решают подруги.
4. Нажмите **Сохранить**. Данные хранятся в браузере этого компьютера (localStorage) — открывайте игру на девичнике на том же ноутбуке и в том же браузере, где заполняли настройку.

## Как играть

1. На обложке нажмите **«Начать квест»**.
2. Раунды идут подряд, счёт баллов виден слева. В раунде 1 невеста отвечает вслух, затем открывается ответ жениха; за промах — фант. В раунде 3 карту испытания нужно перевернуть кликом.
3. После третьего раунда появится вердикт: процент готовности к свадьбе, разбивка по раундам и шуточный прогноз семейной жизни.
4. Кнопка **«Сыграть ещё раз»** сбрасывает счёт (ответы жениха из настройки сохраняются).
